## 🚀 How to Host for FREE on GitHub Pages

This portfolio is built with pure HTML5, Vanilla CSS3, and JavaScript ES6+ (Zero build tools or Node.js dependencies required).

1. Log in to [GitHub](https://github.com/) and create a new repository (e.g. `portfolio` or `rammohan-portfolio`).
2. Upload all files from this project folder:
   - `index.html` (Main portfolio page)
   - `admin.html` (Admin CMS Dashboard)
   - `data.json` (Database backup)
   - `css/` (`style.css`, `admin.css`)
   - `js/` (`data.js`, `main.js`, `admin.js`)
   - `assets/` (Images, icons, artwork)
3. In your GitHub repository, navigate to **Settings** → **Pages**.
4. Under **Branch**, select `main` (or `master`) and directory `/ (root)`, then click **Save**.
5. Your website will be live in ~1 minute at:
   `https://<your-github-username>.github.io/<repo-name>/`!

## 🔐 How to Use the Admin CMS Dashboard

1. Open [admin.html](file:///admin.html) in your browser (or click the 3D **Admin CMS** button in the footer).
2. Enter your Security PIN: **`1234`** (Changeable in the *Backup & Sync* tab).
3. **Add or Edit Projects**:
   - Navigate to **Project Manager** → Click **"➕ Upload New Work"**.
   - Fill in Project Title, select Category & Subcategory, and toggle **"⭐ Feature in Hero Slider"**.
   - Upload multiple images from your computer or phone, set the main thumbnail banner, or attach MP4/YouTube links.
   - Click **Save Project** — updates appear instantly on your live portfolio!
4. **Manage Services**:
   - Navigate to **Services Manager (⚡)** to add, edit, or delete your service offerings.
5. **Manage Profile & Social Links**:
   - Update your Name, Bio, Phone, WhatsApp, and social media handles under **Profile & Socials**.
6. **Save Changes to GitHub**:
   - Go to **Backup & Sync** → Click **"💾 Download data.json"**.
   - Commit the downloaded `data.json` to your GitHub repository to lock in your live data forever.
